# Syntra Spaces · Coming soon

Página de pré-lançamento da Syntra Spaces, com captação de e-mails para a lista de espera, e o primeiro esboço do painel do produto.

## O que tem aqui

- **Página "em breve"** em React, com a identidade da Syntra
- **Prévia do painel:** cards de métricas, tabela de projetos, feed de atividades e sidebar
- **Versão estática** em `projetoSite/` (HTML, CSS e JS puros) com endpoint PHP de inscrição (`api/subscribe.php`) para hospedagem compartilhada

## Stack

React 18 · Vite · TypeScript · Tailwind CSS · shadcn/ui · PHP (inscrição na versão estática)

## Como rodar

```sh
npm install
npm run dev
```
